# 🎮 Mega Man Game

Protótipo de jogos de plataforma inspirado nos clássicos Mega Man e Mega Man X, desenvolvido em Python utilizando a biblioteca Pygame.

## 📌 Sobre o projeto

Projeto desenvolvido para explorar conceitos de programação e desenvolvimento de jogos 2D.

O projeto possui duas versões:

- Mega Man Classic
- Mega Man X

## 🛠️ Tecnologias utilizadas

- Python
- Pygame

## 🎯 Conceitos aplicados

- Lógica de programação
- Programação modular
- Estruturas de dados
- Movimentação de personagens
- Detecção de colisões
- Animação de sprites
- Mecânicas de combate
- Gerenciamento de áudio
- Desenvolvimento de jogos 2D

## 🎮 Funcionalidades

- Movimentação do personagem
- Sistema de pulo
- Ataques
- Colisões
- Animações
- Efeitos sonoros
- Elementos de cenário
